THE NORTH STAR — READ BEFORE EVERYTHING ELSE

sqftLab is NOT a property listing portal.
sqftLab is a data intelligence platform.


The single most important feature — seen in the product screenshot —
is the PROPERTY INTELLIGENCE REPORT. When a user looks at any property
in the UAE, sqftLab runs this analysis automatically:


TRANSACTION DATA → COMPS → AED/SQFT → FAIR VALUE
  → RENTAL YIELD → TREND → INVESTMENT SCORE → VERDICT

This is the pipeline that defines sqftLab. Every page, every feature,
every design decision serves this mission: tell the user what a
property is actually worth and whether it is a good investment —
based on government transaction data, not agent estimates.


Competitors (Bayut, PropertyFinder, Dubizzle) show listings.
sqftLab runs the analysis. That is the difference.

PART 2 — THE PROPERTY INTELLIGENCE REPORT

The Core Feature of sqftLab

This is the feature shown in the screenshot. Every property in sqftLab
runs through this 8-step pipeline and produces a one-page intelligence
report. This is what makes sqftLab a data platform, not a portal.


2.1 The Pipeline

STEP 1: TRANSACTION DATA
  Pull all DLD-registered transactions within 500m or same sub-community,
  same property type, last 24 months. Show: count, date range, source.
  "Based on 47 registered DLD transactions in Downtown Dubai,
   1–3 bed apartments, Jan 2024–Sep 2026"

STEP 2: COMPS (Comparable Sales)
  Top 5 most similar transactions:
  - Same sub-district
  - ±20% of subject property's sqft
  - Last 12 months
  - Same type (apartment/villa/etc)
  Show each comp: date, size, price, PSF, floor (if available)
  Highlight which comps are above/below subject price

STEP 3: AED/SQFT ANALYSIS
  Subject property PSF vs:
  - District 30-day avg PSF
  - District 12-month avg PSF
  - City avg PSF (Dubai or AD)
  - Asset class avg PSF (apartments vs villas)
  Show as a horizontal bar position within the range

STEP 4: FAIR VALUE
  Calculated from comps + district PSF avg:
  Fair value range: AED X,XXX,XXX – AED Y,YYY,YYY
  vs Asking price: AED Z,ZZZ,ZZZ
  Verdict: "Below fair value" / "Within fair value" / "Above fair value"
  % premium or discount to fair value

STEP 5: RENTAL YIELD
  Gross yield: avg district annual rent / asking price
  Net yield: (avg rent – service charges – mgmt fee) / asking price
  vs District avg yield
  vs Abu Dhabi / Dubai average
  Ejari-sourced contracted rents (not listing estimates)

STEP 6: PRICE TREND
  Subject property's district PSF trend: 12M chart
  Is the district trending up/down/flat?
  Momentum score for the district
  Comparison: property PSF vs trend line

STEP 7: INVESTMENT SCORE (0–100)
  Weighted composite of:
    PSF vs fair value       (25%)
    Rental yield            (25%)
    Price momentum          (20%)
    Neighbourhood score     (15%)
    Developer track record  (15% — off-plan only)
  Display as circular score ring with colour coding:
    80–100: Strong buy  (green)
    65–79:  Good value  (teal)
    50–64:  Neutral     (amber)
    0–49:   Caution     (red)

STEP 8: VERDICT
  One-sentence plain-English conclusion:
  "This 2-bed in Downtown Dubai is priced 8% below the district
   average PSF of AED 2,240. Based on 47 comparable DLD transactions,
   fair value is AED 1.28M–1.44M. At AED 1.32M, this is within fair
   value range with a strong 6.2% gross yield. Investment score: 74/100."
  + 3 bullet risk flags (if any):
    ⚠ Service charge above district average
    ⚠ District PSF trend declining 3M
    ✓ Developer has 94% on-time delivery rate

function scoreColour(score: number): string {
  if (score >= 80) return 'var(--score-a)'   // green
  if (score >= 65) return 'var(--score-b)'   // teal
  if (score >= 50) return 'var(--score-c)'   // amber
  return 'var(--score-d)'                     // red
}

function scoreLabel(score: number): string {
  if (score >= 80) return 'Strong buy'
  if (score >= 65) return 'Good value'
  if (score >= 50) return 'Neutral'
  return 'Caution'
}

2.4 Verdict Auto-Generation

// src/lib/verdict.ts

export function generateVerdict(data: PropertyIntelligence): string {
  const {
    district, beds, propertyType, askingPrice,
    fairValueLow, fairValueHigh, psfVsDistrictDelta,
    grossYield, investmentScore, transactionCount,
    districtTrend12m
  } = data

  const fairValueMid = (fairValueLow + fairValueHigh) / 2
  const vsAsk = ((askingPrice - fairValueMid) / fairValueMid) * 100
  const position = vsAsk < -5
    ? `priced ${Math.abs(vsAsk).toFixed(0)}% below fair value`
    : vsAsk > 5
    ? `priced ${vsAsk.toFixed(0)}% above fair value`
    : 'within fair value range'

  return `This ${beds}-bed ${propertyType} in ${district} is ${position}. ` +
    `Based on ${transactionCount} comparable DLD transactions, fair value is ` +
    `AED ${fmtM(fairValueLow)}–${fmtM(fairValueHigh)}. ` +
    `At AED ${fmtM(askingPrice)}, it offers a ${grossYield.toFixed(1)}% gross yield ` +
    `against a district average PSF trend of ${districtTrend12m > 0 ? '+' : ''}` +
    `${districtTrend12m.toFixed(1)}% over 12 months. ` +
    `Investment score: ${investmentScore}/100.`
}

2.5 Risk Flags

export function getRiskFlags(data: PropertyIntelligence): RiskFlag[] {
  const flags: RiskFlag[] = []

  if (data.serviceCharge > data.districtAvgServiceCharge * 1.15)
    flags.push({ type: 'warn', text: 'Service charge above district average' })

  if (data.districtMomentum < 45)
    flags.push({ type: 'warn', text: 'District PSF momentum is below neutral' })

  if (data.psfVsDistrictDelta > 15)
    flags.push({ type: 'warn', text: 'Asking PSF significantly above district avg' })

  if (data.developerOnTimeRate && data.developerOnTimeRate > 88)
    flags.push({ type: 'ok', text: `Developer has ${data.developerOnTimeRate}% on-time delivery rate` })

  if (data.grossYield > data.cityAvgYield + 1)
    flags.push({ type: 'ok', text: 'Yield above city average — strong income potential' })

  if (data.transactionCount < 5)
    flags.push({ type: 'warn', text: 'Fewer than 5 recent comps — lower data confidence' })

  return flags
}

// src/lib/payments.ts
// THIS IS THE SINGLE SOURCE OF TRUTH FOR PAYMENT STATE

export const PAYMENTS_ENABLED = false  // ← flip to true when ready

export type ToastFn = (msg: string) => void
let _toast: ToastFn | null = null

export function registerToast(fn: ToastFn) { _toast = fn }

export function handlePaymentAttempt(
  e?: React.MouseEvent | React.TouchEvent | Event
) {
  if (e) {
    e.preventDefault()
    e.stopPropagation()
    if ('nativeEvent' in e) e.nativeEvent.stopImmediatePropagation()
  }
  _toast?.('Paid plans launching soon — you\'ll be the first to know.')
  // Log the attempt for analytics (not to Stripe)
  console.info('[sqftLab] Payment attempt blocked — PAYMENTS_ENABLED=false')
  return false
}

// src/components/Toast/index.tsx
'use client'
import { useState, useEffect } from 'react'
import { registerToast } from '@/lib/payments'

interface ToastState {
  message: string
  visible: boolean
}

export function ToastProvider({ children }: { children: React.ReactNode }) {
  const [toast, setToast] = useState<ToastState>({ message: '', visible: false })

  useEffect(() => {
    registerToast((msg) => {
      setToast({ message: msg, visible: true })
      setTimeout(() => setToast(t => ({ ...t, visible: false })), 4200)
    })
  }, [])

  return (
    <>
      {children}
      {toast.visible && (
        <div className="toast g2" role="alert" aria-live="polite">
          <div className="toast-icon">◉</div>
          <span className="toast-msg">{toast.message}</span>

      )}
    </>
  )
}
